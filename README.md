# Goodnight 貴族計算

本專案為一套針對 Goodnight 平台所設計的貴族升級成本分析工具，
協助使用者從當前讚數出發，推算至目標爵位所需資源與預估金額，
以提升決策效率並降低不必要的課金成本。

---

## 專案目的

Goodnight 爵位系統具備一定程度的機制複雜性，
包含倍率變化、資源轉換與升級節點差異。

多數使用者在缺乏完整資訊的情況下，容易產生以下問題：

* 升級策略不明確，導致資源配置不佳
* 在非最佳時機進行續等或升級
* 無法有效預估整體花費成本

本工具的目標，即在於提供一個清晰、可量化的決策依據。

---

## 功能說明

* 輸入目前讚數與目標爵位
* 支援多種倍率設定（30x、25x、20x 等）
* 自動計算：

  * 剩餘所需讚數
  * 對應罐頭需求量
  * 預估花費金額（新台幣）
* 提供基本策略建議，協助判斷升級時機

---

## 使用情境

本工具適用於以下使用者：

* 希望精準掌握升級成本的進階玩家
* 有固定課金行為，需優化資源配置者
* 直播主或高互動使用者，需規劃長期爵位策略者

## 設計觀點

本專案不僅為單純的計算工具，而是以「決策輔助系統」為核心進行設計。

透過數據轉譯與流程簡化，將原本隱性的成本結構視覺化，
讓使用者能在操作過程中，即時理解不同選擇所帶來的影響。

其本質在於降低資訊不對稱，並提升行為決策的精準度。
